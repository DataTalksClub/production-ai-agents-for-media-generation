# Source and adaptation notes

Inspected 2026-11-05. The lessons are newly authored in the course's existing five-lesson structure. These links identify source evidence, not a claim that live GPU runs were performed.

- [Build a Media Agent workshop](https://github.com/DataTalksClub/build-media-agent-workshop/blob/19efde12a020747a17575e81769a15ee864c2229/01_simple_media_agent.ipynb): `ImageGenerator` demonstrates the prompt → image request → base64 decode → local file boundary. This module reimplements that small API pattern with the standard library and adds explicit configuration, authentication, bounded readiness, metadata and offline checks. No notebook is copied wholesale; the LLM/tool loop stays in Module 2.
- [DTC preparing code lesson](https://github.com/DataTalksClub/machine-learning-zoomcamp/blob/9bb19da5777191f0dc0a038f93ef1b429db5a2bb/09-serverless/04-preparing-code.md) and [DTC agentic loop lesson](https://github.com/DataTalksClub/llm-zoomcamp/blob/main/01-agentic-rag/14-agentic-loop.md): teaching style references for short explanations, nearby code, experiments and transitions. Their prose/code is not reproduced as lesson text.
- [Sana server](https://github.com/nebius/serverless-ai-cookbook/blob/d1d9cf7530d79dd4d49023003575a36cb7fd0a3c/templates/endpoint-sana/serve.py), [Dockerfile](https://github.com/nebius/serverless-ai-cookbook/blob/d1d9cf7530d79dd4d49023003575a36cb7fd0a3c/templates/endpoint-sana/Dockerfile), and [template instructions](https://github.com/nebius/serverless-ai-cookbook/blob/d1d9cf7530d79dd4d49023003575a36cb7fd0a3c/templates/endpoint-sana/README.md): API fields, readiness behavior, CUDA runtime and Sana component precision. The server does not supply `revision` to its loader; a client model ID is not a revision pin.
- [Pinned Sana checkpoint](https://huggingface.co/Efficient-Large-Model/Sana_1600M_1024px_diffusers/tree/ac0da2ff55fbe434795be0dce883042e4d49e2fc): resolved using the Hub API. Model weights are not bundled.
- [Diffusers Sana documentation](https://huggingface.co/docs/diffusers/api/pipelines/sana): pipeline entry point and model variants.
- [PyTorch reproducibility](https://docs.pytorch.org/docs/stable/notes/randomness.html): boundaries on deterministic-output claims.
- [First Job cookbook](https://github.com/nebius/serverless-ai-cookbook/blob/d1d9cf7530d79dd4d49023003575a36cb7fd0a3c/quickstarts/first-job.md) and [Job CLI reference](https://docs.nebius.com/cli/reference/ai/job/create): resource flags, explicit timeout, S3 volume syntax and lifecycle commands. Cookbook uses 15m; current CLI reference says minimum 1h. Recheck installed CLI during dry run.
- [Serverless pricing](https://docs.nebius.com/serverless/pricing-quotas): Compute pricing applies and stopped-resource/storage lifecycles differ. No price is hard-coded in this module.

The supplied private course-design document and Module 1 card informed the standalone code, flat layout, observable outcomes and measurement fields. The repository module README remains the scope authority.
