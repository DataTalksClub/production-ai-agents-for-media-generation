# 4.1 Evaluating Media Quality

In this lesson we start from the rubric developed in [2.5](../02-multi-agent-media-workflows/05-judge-loop.md) and add one style check: "Does this match the reference style?". We build a golden set, a fixed set of briefs with human-labelled outputs, compare the judge's verdicts with those labels, and evaluate a sample run to set a quality baseline. You're done when you can say how often the judge agrees with your labels on the golden set, and `evals.json` holds the baseline pass rate for your sample run.
