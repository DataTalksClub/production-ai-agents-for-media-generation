# Judge fixtures (lesson 2.5)

Two keyframes with a known verdict, so the judge is tested on both sides:

| File | Expected | Label |
| --- | --- | --- |
| `bad_keyframe.png` | `RETRY` | [bad_keyframe.json](bad_keyframe.json) |
| `good_keyframe.png` | `PASS` | [good_keyframe.json](good_keyframe.json) |

The PNGs are generated by the course author on the Sana Endpoint and checked by eye against
the label (`checked_against_image: true`) before release. Until then, `--fake` runs use
placeholders and say so.
